# HashMap

This folder contains HashMap-based DSA problems that helped me understand common patterns such as:

- Frequency Counting
- Value → Index Mapping
- Duplicate Detection
- Character Frequency Comparison
- Finding the Maximum Frequency Element


## Concepts Learned

- Dictionaries (HashMaps) in Python
- `items()`, `keys()`, `values()`
- Frequency counting
- Tracking indices
- Iterating through key-value pairs
- Time Complexity: Most solutions run in **O(n)** time.
