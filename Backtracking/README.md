
# Backtracking

This folder contains my practice and implementations of backtracking problems in Java.

Backtracking is a problem-solving technique where we make a choice, explore the possible solution, and then undo that choice to try another possibility.

Topics and problems covered:
- Subsets
- Take and Not-Take approach
- Recursion with backtracking
- ArrayList based backtracking
- More problems will be added as I practice

The main goal of this section is to understand how recursion and backtracking work together and improve problem-solving skills.
