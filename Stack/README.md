# Stack

This folder contains my practice problems and implementations related to the Stack data structure.

## About Stack

A stack is a linear data structure that follows the **LIFO (Last In, First Out)** principle. The last element added to the stack is the first one to be removed.

In Python, a list can be used as a stack using:

* `append()` to push an element
* `pop()` to remove the top element
* `stack[-1]` to access the top element

## Basic Operations

* Push
* Pop
* Peek / Top
* Check if the stack is empty

Most of these operations take **O(1)** time.
